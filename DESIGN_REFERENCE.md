# Guardian UI implementation

Reference supplied by the project owner:

Figma Make: https://www.figma.com/make/ZBi6FSwIyyJ2AeRTyu5Wvv/Guardian-app-UI-design?t=4ZCn7SSAR2mVc4OB-20&fullscreen=1

The uploaded UI video was used as the implementation reference for the post-login application screens.

Implemented navigation:
- Home
- Health
- Alerts
- Recordings
- Profile

Implemented interactions:
- 2-second long-press SOS
- Heart-rate threshold at 150 BPM
- Demo 150 BPM test button
- BLE badge connection entry point
- Alert expansion and acknowledgement
- Recording play/pause simulation with waveform progress
- Guardian add/remove with minimum-one-guardian rule
- Notification and safe-area toggles
- Device/battery/connection status

The existing login page was intentionally left in place.
